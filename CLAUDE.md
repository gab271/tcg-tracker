# Reglas del proyecto TCG Tracker
- Stack: Next.js 15, TypeScript, Tailwind CSS, Supabase, Framer Motion, GSAP
- Estilo visual: dark theme, estética "vault de lujo", acentos dorados y holográficos
- Animaciones: siempre usa Framer Motion para transiciones de UI y GSAP para scroll
- Base de datos: siempre usa el cliente de Supabase, nunca hardcodees credenciales
- Idioma del código: inglés. Comentarios: español
